# /omg-pay

**一句話觸發完整歐買尬金流整合**。AI 接收此指令後，應依 `guides/00-onboarding.md` 定義之 onboarding 流程四問一次性呈現，並於使用者回覆「全部」或「預設」後進入 15 步自動整合。

## 用法

```
/omg-pay
```

或附帶商品類型：

```
/omg-pay 線上課程
/omg-pay 實體商品
/omg-pay 訂閱服務
```

## AI 執行流程

1. 讀取 `SKILL.md` 之 §0 執行規則
2. 依 `guides/00-onboarding.md` 之四問呈現 onboarding
3. 使用者回覆後進入 15 步執行順序
4. 執行末端統一收集 `{{商家名}}`、`{{統一編號}}` 等變數
5. 產出完整檔案樹並於 `templates/omg-test-console/` 執行全鏈路驗證
6. 交付整合結果並說明部署與綁定步驟

## 預設套用之模組

若使用者回覆「全部」或「預設」，AI 應套用下列全部模組：

- FastAPI 後端骨架
- Race-safe webhook idempotency handler
- 測試環境儀表板
- 正式環境唯讀探測儀表板
- Telegram 通知機器人
- Discord 通知機器人
- 退款安全機制（警示但允許通過）
- 首頁與頁尾必要揭露
- 商品頁必要揭露
- 服務條款、隱私權政策、退貨退款政策公版

## 不執行之操作

- 不得於正式環境執行 `create_order`
- 不得將金鑰寫入 repo
- 不得以硬性阻擋方式實作退款限額
- 不得於交付物中使用「歐付寶」字樣（應為「歐買尬」）
