# Guide 12 — 商品頁必要揭露

> **免責聲明**：本範例僅為參考，不構成法律意見。上線前請委請法務顧問或律師審閱，並依實際營運狀況調整。

本指南定義商品頁面應具備的必要揭露元素，補充 `guides/11-merchant-homepage.md` 所規範之全站層級揭露。

## 核心原則

商品頁是消費者做出購買決定的最後一步，揭露資訊應達到「消費者無需離開商品頁即可知悉所有重要條件」之程度。

## 必要揭露欄位

### 1. 商品基本資訊

- **商品名稱**：與出貨實品名稱一致
- **商品規格**：顏色、尺寸、重量、容量、材質等
- **商品型號 / SKU**：便於客服查詢
- **商品照片**：至少一張主圖，建議 3 至 5 張不同角度
- **商品描述**：真實且具體，避免誇大或誤導

### 2. 價格資訊

- **售價**：以新台幣含稅標示，NTD 或「元」均可
- **原價與促銷期間**：若為促銷商品，同時揭示原價與促銷截止時間
- **運費**：若計入總金額，應於結帳前明確呈現；若免運費，應標示免運費條件
- **分期付款方案**：若支援信用卡分期，列出各期數與每期金額

### 3. 出貨與交付

**實體商品**：

- 預計出貨時間（例：付款完成後 3 個工作日內）
- 可配送地區
- 物流方式（宅配 / 超商取貨 / 自取）
- 特殊包裝（冷藏、冷凍、易碎等）

**數位商品 / 線上課程**：

- 交付方式（例：付款後於會員中心立即啟用）
- 使用期限（永久 / 年約 / 月約）
- 存取平台（Web / App / 下載檔案）
- 技術需求（作業系統、裝置規格、瀏覽器版本）

### 4. 七日猶豫期揭露

依消保法 §19 規定，通訊交易消費者享有商品收受後七日內無條件解約權。商品頁必須明確標示下列兩種情境之一：

**適用七日猶豫期**：

> 依消費者保護法第 19 條規定，本商品為通訊交易商品，消費者享有商品收受後七日內之解除權。解約時請保持商品完整並檢附原廠包裝、配件與發票。

**不適用七日猶豫期（須標示理由）**：

> 本商品屬「通訊交易解除權合理例外情事適用準則」所定例外情事，[具體理由]，故不適用消費者保護法第 19 條第 1 項規定之七日解除權。

例外情事之具體理由範例：

- 易於腐敗、保存期限較短或解約時即將逾期之商品
- 依消費者要求所為之客製化給付
- 已拆封之個人衛生用品或個人貼身用品
- 報紙、期刊、雜誌
- 經消費者拆封之影音商品或電腦軟體
- 非以有形媒介提供之數位內容，經消費者事先同意後始提供
- 已拆封之個人化商品

**重要**：不適用猶豫期之商品，必須於商品頁 **明顯位置** 揭露（非僅寫於條款內），並建議於結帳前以彈窗或勾選框讓消費者確認知悉。

### 5. 退貨條件

即使商品適用七日猶豫期，退貨仍有合理條件：

- 商品須保持原狀（未拆封 / 未使用 / 可復原）
- 原包裝、配件、贈品、發票須一併退回
- 部分特殊商品不適用（例如已拆封內衣褲、食品等）
- 退貨運費由誰負擔（若消費者無正當理由解約，商家可請其負擔）

### 6. 商品頁常見違規事項

AI 產出商品頁模板時應避免下列常見錯誤：

- 價格未含稅或未清楚標示
- 運費於結帳時才出現（應於商品頁或購物車預先標示）
- 猶豫期揭露寫於服務條款深處，消費者不易察覺
- 誇大效能或療效（例：保健食品宣稱療效、美妝商品宣稱「立即變白」）
- 使用「絕對」、「唯一」、「最強」等違反公平交易法之字眼
- 折扣標示不實（例：標示「原價」高於實際售價）

## 結帳前再次提醒

即使商品頁已揭露，建議於結帳流程中再次提醒下列事項，並以勾選框讓消費者確認：

- 確認商品規格與數量
- 確認適用 / 不適用 7 日猶豫期
- 確認已閱讀退貨退款政策
- 確認已閱讀服務條款與隱私權政策

此再次提醒機制可降低爭議發生率，並於事後爭議處理時作為商家已履行告知義務之證據。

- [ ] 商品名稱與型號
- [ ] 商品照片至少一張
- [ ] 售價以含稅 NTD 標示
- [ ] 運費揭露（明確標示或標示免運費條件）
- [ ] 出貨時間說明
- [ ] 物流方式說明
- [ ] 七日猶豫期是否適用之明確標示
- [ ] 若不適用，列出具體例外理由
- [ ] 退貨條件與責任歸屬
- [ ] 付款方式列表並標示金流服務商為歐買尬

任一項缺漏時，AI 應於交付訊息中提醒使用者補齊。
