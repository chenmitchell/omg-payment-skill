# Guide 11 — 首頁與頁尾必要揭露

> **免責聲明**：本指南所列揭露項目依據台灣現行消保法、個資法、電子商務發展條例及主管機關行政指導彙整。本範例僅為參考，不構成法律意見。上線前請委請法務顧問或律師依商家實際營運狀況審閱後調整。

本指南列出商家官方網站之首頁與頁尾應具備的必要揭露元素，適用於於台灣境內向消費者銷售商品或服務之網路商店。

## 為何需要首頁揭露

台灣主管機關要求網路商家於顯眼位置揭露基本營業資訊，使消費者於購買前可辨識交易對象、查詢客訴管道、確認履約與退貨條件。未揭露或揭露不完整，可能觸犯以下法規：

- 消費者保護法 §17（定型化契約應記載事項）
- 電子商務發展條例相關規範
- 公平交易法 §21（不實廣告）
- 個人資料保護法 §8（告知義務）

商家初次上線前應逐項核對本指南之清單，確保所有必要揭露均已落實。

## 首頁必要揭露元素

以下項目應於首頁或可從首頁一鍵到達的頁面中呈現。

### 1. 基礎商家資訊

必須於網站頁尾或「關於我們」頁面標示：

- **營業人名稱**：與經濟部商業登記一致之公司或商號全名
- **統一編號**：8 碼統編
- **營業地址**：實際營業處所地址（非郵政信箱）
- **負責人姓名**：登記負責人
- **客服聯絡方式**：至少提供一組 Email 與一組電話，並標示服務時間

對於僅持有扣繳單位編號的個人賣家，應另行標示「個人賣家」身分，並依主管機關規定揭露其他資訊。

### 2. 商品與價格揭露

- 所有商品價格必須為 **含稅價**
- 若有運費、手續費、包材費等附加費用，應於商品頁與結帳頁明確列示
- 促銷價格應同時標示原價與促銷期間

### 3. 交易條款連結

首頁頁尾必須提供下列連結，使消費者於結帳前可存取：

- 服務條款（`/legal/tos`）
- 隱私權政策（`/legal/privacy`）
- 退貨退款政策（`/legal/refund`）
- 會員條款（若有會員制度）

連結文字應清楚可辨識，不得以淺色字或極小字體隱藏。

### 4. 付款方式揭露

明確標示所接受的付款方式，例如：

- 信用卡（一次付清 / 分期 3/6/12/18/24/30 期 / 定期定額；銀聯卡需另申請開通）
- ATM 虛擬帳號
- 超商代碼繳費（ChoosePayment=CVS）
- 超商快付（ChoosePayment=BarcodeATM，三段條碼）
- AFTEE 先享後付（ChoosePayment=AFTEE）

並標示金流服務商名稱（例：「本站信用卡收單由 MacroWell OMG 歐買尬提供」）。

### 5. 物流與運送說明

- 可配送地區範圍
- 預計出貨時間（例：完成付款後 3 個工作日內）
- 運送方式與運費計算
- 特殊商品（大型、冷鏈、低溫宅配）之額外說明

若屬數位商品或線上課程，應說明交付方式（例：「付款成功後即於會員中心啟用」）。

### 6. 七日猶豫期說明

對於適用消保法通訊交易解約權之商品，應於商品頁與退款頁明確告知「消費者享有商品收受後七日內無條件退貨權利」。

對於不適用猶豫期之商品（依「通訊交易解除權合理例外情事適用準則」），應於商品頁上明確標示不適用理由，例如：

- 易於腐敗或保存期限較短之商品
- 客製化商品
- 報紙、期刊、雜誌
- 經拆封之個人衛生用品
- 數位內容（已下載或開通使用）

### 7. 履約保證機制

若商家年營收達一定規模，應依主管機關規定採取履約保證措施並於網站揭露。常見的履約保證方式：

- 金融機構履約保證（多數金流服務商已提供）
- 同業公會連帶擔保
- 其他經主管機關認可之方式

## 頁尾區塊範例

```html
<footer class="site-footer">
  <div class="footer-about">
    <h3>{{商家名}}</h3>
    <p>營業人：{{商家名}}</p>
    <p>統一編號：{{統一編號}}</p>
    <p>負責人：{{負責人}}</p>
    <p>營業地址：{{營業地址}}</p>
    <p>客服電話：{{客服電話}}（週一至週五 10:00–18:00）</p>
    <p>客服信箱：<a href="mailto:{{客服Email}}">{{客服Email}}</a></p>
  </div>

  <div class="footer-legal">
    <h4>條款與政策</h4>
    <ul>
      <li><a href="/legal/tos">服務條款</a></li>
      <li><a href="/legal/privacy">隱私權政策</a></li>
      <li><a href="/legal/refund">退貨退款政策</a></li>
    </ul>
  </div>

  <div class="footer-payment">
    <h4>付款方式</h4>
    <p>信用卡（一次付清 / 分期 / 定期定額）、ATM 虛擬帳號、超商代碼、超商快付</p>
    <p>本站信用卡收單由 MacroWell OMG 歐買尬全方位金流提供</p>
  </div>

  <div class="footer-copyright">
    <p>&copy; {{年份}} {{商家名}}. All rights reserved.</p>
  </div>
</footer>
```

## AI 產出檢查清單

AI 依據使用者於 onboarding 填入之 `{{商家名}}`、`{{統一編號}}`、`{{營業地址}}` 等變數，產出頁尾區塊後，必須逐項確認：

- [ ] 頁尾包含營業人名稱
- [ ] 頁尾包含統一編號
- [ ] 頁尾包含營業地址
- [ ] 頁尾包含客服 Email 與電話
- [ ] 頁尾包含三項條款政策連結
- [ ] 頁尾標示所接受付款方式
- [ ] 頁尾標示金流服務商為歐買尬（MacroWell OMG），非歐付寶
- [ ] 若商品含實體商品，需包含出貨時間與運費說明

若任一項缺漏，AI 應於交付訊息中明確告知使用者並建議補齊。
